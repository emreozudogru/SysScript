# Security Policy

## Scope

Most scripts in this repository execute remote administrative actions and can have high operational impact.

## Safe-Use Recommendations

- Run scripts in a lab/test environment first.
- Double-check OU/domain targeting filters before production execution.
- Run mass-restart or profile-deletion scripts only during planned maintenance windows.
- Apply the principle of least privilege to accounts used for script execution.

## Vulnerability Reporting

If you discover a security issue, please avoid opening a public issue first. Share details privately with the repository maintainer.
