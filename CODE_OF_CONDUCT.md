# Code of Conduct

This project aims to maintain a respectful and inclusive environment for all contributors.

## Expected Behavior

- Communicate in a constructive and professional way.
- Focus criticism on code and technical decisions, not individuals.
- Respect contributors with different experience levels.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory or exclusionary language.
- Intentionally misleading technical guidance.

## Enforcement

Maintainers may edit or remove content that violates these rules and may restrict contribution privileges when necessary.
